# Security policy

## Supported version

Only the latest deployment from the default branch is supported.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's
**Security** tab and select **Report a vulnerability** to submit a private
security advisory to the maintainers.

Include reproduction steps, affected URLs or files, expected impact, and any
suggested remediation. Please avoid accessing, changing, or retaining data that
does not belong to you while testing.

This project does not require user accounts and is not intended to collect
personal information.
