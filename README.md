# Богатырский нрав

Интерактивный психологический квиз по мотивам русских былин. Двадцать пять утверждений сопоставляют профиль участника с одним из двенадцати литературных архетипов — от Ильи Муромца и Добрыни Никитича до Настасьи Микулишны, Садко и Сухмана.

## Что внутри

- пятибалльная шкала ответов с доступными radio-контролами;
- модель из пяти поведенческих осей и двенадцати результатов;
- подробный результат: сильные стороны, «теневая» сторона, контекст былины и близкие архетипы;
- адаптивная вёрстка для телефона и десктопа;
- полностью русскоязычный пользовательский интерфейс;
- социальная карточка в визуальном стиле проекта.

Тест представляет собой культурно-развлекательную интерпретацию фольклорных образов и не является психологической диагностикой.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## Источниковая основа

Архетипы опираются на сюжеты докиевского, киевского и новгородского циклов былин. Основные справочные материалы:

- [«Богатыри», Большая российская энциклопедия](https://old.bigenc.ru/literature/text/1871524)
- [«Былина», Большая российская энциклопедия](https://bigenc.ru/c/bylina-d8ce91)
- [«Русские богатыри», Культура.РФ](https://www.culture.ru/materials/244761/dobrym-lyudyam-na-poslushane)
- [«Самая древняя былина Руси», Культура.РФ](https://www.culture.ru/s/vopros/byliny)
